Projection :







		-------------- Query Operators -------------

Comparision Operators:

$eq - Values are equal  ( office> db.employee.find({ city:{ $eq:'Coimbatore' }})  )
$ne - values are not equal  (  office> db.employee.find({ city:{ $ne:'Coimbatore' }})  )
$gt - Value is greater than another value
$gte - Value is greater than or equal to another value
$lt - Value is less than another value
$lte - Value is less than or equal to another value
$in - Value is matched within an array  (  office> db.employee.find({ age:{ $in:[24,25,30] }})  )


Logical Operators:

$and - Returns documents where both queries match
		office> db.employee.find({ $and:[ {city:{$eq:'Coimbatore'}},{age:{$eq:27}} ]})
$or - Returns documents where either query matches
		office> db.employee.find({ $or:[ {city:{$eq:'Coimbatore'}},{city:{$eq:'Pollachi'}} ]})
$not - Returns documents where both queries fail to match
$not - Returns documents where the query does not match


Evaluation Operators:

$regex - Allows the use of regular expressions
		test> db.employee.find({ name:{ $regex:'^M' }})   ---   test> db.employee.find({ name:{ $regex:'^M', $options:'i' }})
$where - Allows the use of Javascript expressions
		test> db.employee.find({ where:function(){ return this.name=='Brindha'} })
$test - performs a text search on the context
		test> db.articles.find({ $test:{ $search: 'back coffee cake' }})
